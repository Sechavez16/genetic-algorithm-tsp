# Algoritmo Genético para el Problema del Viajante (TSP)

## Descripción del proyecto

Implementación académica de un algoritmo genético aplicado al problema del viajante, conocido como Travelling Salesman Problem (TSP).

El TSP consiste en encontrar un recorrido que visite un conjunto de ciudades y regrese al punto de partida, buscando minimizar la distancia total recorrida.

Debido al crecimiento del número de recorridos posibles a medida que aumenta la cantidad de ciudades, el problema es útil para estudiar técnicas de optimización combinatoria y búsqueda aproximada.

## Objetivos

- Comprender los fundamentos de los algoritmos genéticos.
- Representar soluciones candidatas para un problema de optimización.
- Implementar una población inicial de individuos.
- Definir un mecanismo de evaluación mediante una función de fitness.
- Explorar la evolución de soluciones a través de generaciones.
- Analizar cómo una estrategia evolutiva puede buscar recorridos de menor costo.

## Archivo principal

`Copia_de_Algoritmo_genético_completo_TSP.ipynb`

El notebook contiene la implementación académica del algoritmo genético para el problema del viajante.

## Componentes del algoritmo

### 1. Representación de soluciones

Cada individuo representa una solución candidata al problema mediante un recorrido.

### 2. Población inicial

Se generan individuos que conforman el conjunto inicial de soluciones.

### 3. Función de fitness

Se evalúa la calidad de las soluciones utilizando un criterio relacionado con el costo del recorrido.

### 4. Selección y evolución

Se aplican los mecanismos evolutivos definidos en la implementación para generar nuevas soluciones.

### 5. Evaluación de resultados

Se examinan las soluciones producidas durante la ejecución del algoritmo.

Los operadores concretos y los resultados deben consultarse directamente en el notebook.
